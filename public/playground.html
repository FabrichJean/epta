API Key Management

Create and manage API keys for programmatic access to the API. Use API keys as an alternative to JWT tokens. You can create, list, enable/disable, regenerate (with optional expiration update), and delete API keys. Note: You can use either JWT tokens or API keys throughout this playground - API keys will be prioritized if both are provided.

Create New API Key

💡 Choose between 1-365 days. Shorter expiration periods are more secure.

My API Keys

Test API Key

Test your API key by making a request to the /me endpoint. Usage: Add the X-API-Key header to any API request instead of the Authorization: Bearer header.
Tip: You can also set your API key in the global configuration above to use it automatically in all requests.

Example cURL:
curl -H "X-API-Key: epta_your_api_key_here" ${getBaseUrl() || 'http://localhost:4000'}/me
